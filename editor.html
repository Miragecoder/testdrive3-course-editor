Toolbox

Leg-scoped Tile editing for the active leg map.

Selected cell

Select a cell on the map. Right-click, double-click, or press Enter to open its properties popup. The popup lets you edit tile ID, rotation, and elevation.

Tile palette

Choose a cell and tile preview, then apply it. In paint mode, click map cells to place the selected tile.

Previews are top-down renders of the viewer's reconstructed 3D tile models.

Tile clusters / prefabs

Stamp multi-cell tile patterns in one action. Clusters are tile-only (tile ID, rotation, elevation). Select an anchor cell, Shift+click to define the opposite corner, capture the region, then arm a stamp and click the map to place it.

Anchor: none. Select a cell and use Set anchor, then Shift+click another cell to define a capture region.

When armed, hovering shows a ghost preview and clicking places the cluster as a single undoable stamp. Out-of-bounds stamps are blocked.

Leg-scoped Route markers, branch paths, and opponent AI scripts.

Route markers

Each leg stores three route-trigger tile IDs in the map header. When the player is on a tile with one of these IDs, the game sets the route index used by the scorecard and per-route records.

Cells using these tile IDs are highlighted on the map.

Opponent route scripts

Paths use the course’s lane bank and opponent branch scripts; the finish is detected from tile surface geometry. When a required P.BIN is unavailable, the editor draws a dashed shared-bank candidate instead of presenting it as the in-game route.

Horizon gradient

About these values

The gradient is defined by per-leg color values (not a single global preset). Legs in the same scene can use different combinations, and the preview shows the resulting sky/horizon colors for the selected mode. The preview simulates the in-game VGA banded gradient; warnings appear when palette stepping can create artifacts like a black band.
