About these values

The gradient is defined by per-leg color values (not a single global preset). Legs in the same scene can use different combinations, and the preview shows the resulting sky/horizon colors for the selected mode. The preview simulates the in-game VGA banded gradient; warnings appear when palette stepping can create artifacts like a black band.

Reverse Pacific course

Reverses the leg order, lighting, map placement, finish tile, and racer starts, and generates private SCENE03 banks using SCENE01’s shared lane bank (un-reversed, no mirroring) plus a shared-copy object bank. The exported SCENE03.LST is marked for private O/P banks (0x57=0), and SCENE03O.BIN/SCENE03P.BIN are embedded into SCENE03.DAT for the original engine.
