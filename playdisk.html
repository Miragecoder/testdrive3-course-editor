About

PLAYDISK.DAT stores the car and scene slots shown by the game, plus selection and skill state. Edit slot codes to match the base names of your .LST files (for example CCERV or SCENE03). Unused slots are commonly filled with ? characters.

Default template

Car slots (14)

6-character codes. Active car slots usually start with C and need a matching .LST in the game folder.

Scene slots (8)

8-character codes. Active scene slots usually start with S (for example SCENE01).

Selection & state

These bytes control the default selection and stored skill/state values. Values are written as 16-bit little-endian words unless noted.
